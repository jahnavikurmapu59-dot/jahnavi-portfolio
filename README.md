# Jahnavi Kurmapu — Personal Portfolio

A responsive, single-page portfolio website with a dark purple theme, subtle scroll animations, mobile navigation, project cards, experience timeline and contact links.

## 1. Run locally
1. Extract the ZIP file.
2. Open the `jahnavi_professional_portfolio` folder in Visual Studio Code.
3. Add your portrait as `assets/profile-photo.jpg` (instructions below).
4. Open `index.html` in a browser. For the best development experience, use the VS Code Live Server extension.

No build tools, package installation or backend are required.

## 2. Add your profile photo
- Choose a professional head-and-shoulders photo.
- Crop it vertically (4:5 or 3:4 works well).
- Rename it exactly to `profile-photo.jpg`.
- Place it inside the `assets` folder, replacing the placeholder behavior.

The page currently displays a styled JK placeholder until you add your photo.

## 3. Add your resume
Place your latest PDF in `assets` and name it exactly:
`Jahnavi_Kurmapu_Resume.pdf`

The Download Resume button points to this file.

## 4. Personalize project links
The project GitHub buttons currently point to your GitHub profile:
https://github.com/jahnavikurmapu59-dot

Replace each `href` in the project cards in `index.html` with the exact repository URL for that project when you have it. Do not leave profile links labelled as individual repositories if you later add separate repositories.

## 5. Update details
Review `index.html` before publishing:
- Confirm dates and GPA against your official records.
- Add any additional tools only if you can confidently discuss them.
- Add a project live-demo URL only when the project is deployed and working.
- Update the contact details if they change.

## 6. Publish free with GitHub Pages
1. Create a GitHub repository named `jahnavi-portfolio`.
2. Upload the contents of this folder (the `index.html`, `style.css`, `script.js`, `assets` folder and this README).
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. Your URL will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/jahnavi-portfolio/`

## Notes
- This is a static website; it does not collect form submissions or store visitor data.
- The email contact button opens the visitor's email application.
- Google Fonts are loaded from Google Fonts when the visitor is online.
- Replace the profile placeholder and verify all details before sharing the public URL.
